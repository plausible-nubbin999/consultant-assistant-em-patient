## 🚀 Getting Started

Welcome to **Consultant Assistant EM**, a browser-based patient management tool designed specifically for emergency department and emergency medicine workflows. This application helps you track patients, manage their information, and streamline your daily tasks—all from your web browser.

### What This Application Does

- **Manage Patients**: View and update patient records quickly.
- **Track Workflow**: Monitor patient progress through the emergency department.
- **Access Anywhere**: Since it runs in your browser, no installation is needed on most devices.

## 🛠️ How to Use

1. **Launch the Application**: After installation, open the app. You will see a login screen (if configured) or a main dashboard.
2. **Add a Patient**: Click the "New Patient" button. Enter the patient's name, age, chief complaint, and other details.
3. **Update Status**: Click on a patient's row to view their full chart. Use the dropdown to change their status (e.g., from "Waiting" to "In Treatment").
4. **Save Changes**: All changes are saved automatically. No need to press a save button.
5. **Log Out**: Close the browser tab or click "Logout" to end your session.

## ❓ Troubleshooting

If you encounter issues, try these common fixes:

- **Application won't open**: Ensure your browser is up to date. Clear your browser cache and try again.
- **Download fails**: Check your internet connection. Try using a different browser.
- **Installation blocked**: Windows may show a SmartScreen warning. Click "More info" and then "Run anyway" if you trust the source.
- **Data not saving**: Make sure you have write permissions to the installation folder. Run the application as administrator (right-click > Run as administrator).
